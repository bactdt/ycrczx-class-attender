## Class Attender（Chrome / Edge 扩展）

一个用于个人学习场景的浏览器扩展示例。它在指定站点页面上提供课程入口整理、播放页辅助控制和本地状态面板，便于用户在已登录、已授权访问的前提下管理自己的学习页面。

### 与原版差异

本仓库基于 `cxl086/ycrczx-class-attender` 调整，当前版本为 `1.0.12`。相对原版主要差异如下：

- 新增适配 `https://ycrczx.com/*` 和 `https://yctc.ycrczx.com/*`，并保留 `https://www.ycrczx.com/*` 支持。
- 调整打包脚本，生成的 `dist/class-attender.zip` 会把 `manifest.json` 放在 ZIP 根目录，适合 Edge / Chromium 扩展包结构。
- 仓库内附带已打包文件 `dist/class-attender.zip`，可下载后解压加载。
- 课程详情页提供两个入口：“继续学习”只打开一个未完成课时；“批量打开”最多打开 5 个未完成课时。
- 播放页提供状态面板，展示当前课程、当前/下一课时、解析到的目录和最近执行日志。
- 学习中心页新增课程面板，监听站点课程列表接口返回，解析课程名称、进度和课程入口。
- 学习中心捕获到的未完成课程会保存为本地队列；打开课程或跨课程续学时，会优先进入该课程第一个未完成课时。

### 功能概述

- 课程详情页（`https://ycrczx.com/zzpx/courseDetail/{id}`、`https://www.ycrczx.com/zzpx/courseDetail/{id}`、`https://yctc.ycrczx.com/zzpx/courseDetail/{id}`）：
  - 页面右下角注入“继续学习”和“批量打开(最多5个)”按钮。
  - “继续学习”优先打开第一个未完成课时；若无法判断进度，则打开第一个可识别课时。
  - “批量打开”最多并发打开 5 个未完成课时，避免一次弹出过多窗口。
- 播放页（`/video/courseLearnPage?id=...&&classId=...`）：
  - 辅助点击播放按钮，并在浏览器自动播放策略允许的范围内尝试播放。
  - 提供静音、播放保活、下一节入口识别、状态面板和执行日志。
  - 若当前课程已到最后一课时，可读取学习中心保存的未完成课程队列，进入下一门课程的第一个未完成课时。
- 学习中心页（`/studyCenter/page`）：
  - 监听站点自己的课程列表接口返回，解析课程名称、进度、课程入口。
  - 面板提供“读取当前列表”“打开第一门未完成”“批量打开未完成”。

### 安装与加载

#### 前置要求

- Microsoft Edge 或 Chrome 114+（Manifest V3）。
- 已开启“开发人员模式”：Edge / Chrome → 扩展程序 → 右上角“开发人员模式”。

#### 方式一：加载已解压的扩展

1. 下载/克隆本项目。
2. 打开 `edge://extensions` 或 `chrome://extensions`。
3. 点击“加载解压缩的扩展”。
4. 选择项目根目录，或选择执行 `npm run build` 后生成的 `dist/src` 目录。

#### 方式二：使用 ZIP 包

1. 在项目根目录执行：
   ```bash
   npm run build
   ```
2. 生成的压缩包位于：`dist/class-attender.zip`。
3. 解压后，Edge / Chrome → 扩展程序 → 加载解压缩的扩展，选择解压后的目录。

### 使用说明

#### 登录站点

- 访问目标站点并保持已登录状态。扩展不会提供、保存或绕过登录凭据。

#### 课程详情页

1. 打开课程详情页，例如：`https://ycrczx.com/zzpx/courseDetail/2929`。
2. 页面右下角出现“继续学习”和“批量打开(最多5个)”按钮。
3. 点击“继续学习”会打开一个未完成课时；点击“批量打开”会最多打开 5 个未完成课时。
4. 如弹窗被浏览器拦截，请在地址栏右侧按需允许此站点弹窗。

#### 播放页

- 打开的播放页会显示状态面板，记录播放、跳转和课程目录解析状态。
- 若页面结构、站点规则或浏览器策略发生变化，部分辅助动作可能不会生效，需要用户手动操作。

### 常见问题（FAQ）

- 看不到按钮？
  - 刷新页面，确认 URL 匹配课程详情页或学习中心页。
  - 确认扩展已加载并启用。
- 点击按钮无反应？
  - 检查浏览器是否拦截了弹窗。
  - 页面目录可能是动态加载，先展开或滚动到课程目录区域再点击。
- 播放页辅助动作不生效？
  - 浏览器自动播放策略、站点脚本、iframe 或页面模板变化都可能影响效果。
  - 请提供页面 DOM 片段或截图中的按钮 HTML，便于适配。

### 权限说明

- `host_permissions`: `https://ycrczx.com/*`、`https://www.ycrczx.com/*`、`https://yctc.ycrczx.com/*`，用于在目标页面注入内容脚本。
- `permissions`: `tabs`, `windows`, `scripting`，用于打开页面、静音标签页和内容脚本相关能力。
